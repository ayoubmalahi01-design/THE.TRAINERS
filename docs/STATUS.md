# حالة مشروع THE TRAINERS — 2026-11-19

المرجع المعتمد للحالة هو `docs/RELEASE_STATUS_2026-11-19.md`. التقارير الأقدم في هذا المجلد تاريخية ولا تعكس آخر إصلاحات الواجهة وقاعدة Supabase.

## ما هو موجود ومربوط

- أربعة أدوار: Owner / Manager / Admin / Coach، مع عزل المؤسسات.
- التلاميذ والأقسام والسنوات الدراسية والحضور والحصص والتقارير.
- تقارير المدربين: مسودات خاصة بالمدرب، إرسال نهائي، مراجعة Manager/Admin، حذف المسودة الخاصة فقط، وحذف التقارير النهائية وفق الصلاحيات المحددة.
- كراس خاص بكل مدرب، وملاحظات التلاميذ.
- ملفات طبية للإدارة (Manager/Admin) فقط؛ لا يملك Coach صلاحية قراءة.
- تعاميم ينشرها ويحذفها Manager/Admin، مع قائمة القارئين وغير القارئين لهما فقط.
- محادثات فردية وجماعية وملفات وصور وصوت، مع إيصالات قراءة لكل رسالة ولكل عضو.
- متابعة آلية بعد 5 غيابات متتالية، وإظهارها لأعضاء المؤسسة النشطين حتى حصتين فعليتين بعد العودة.
- سجل تدقيق، وإشعارات داخل التطبيق وRealtime، وPWA.
- العربية والفرنسية والإنجليزية، مع RTL للعربية.

## حالة التحقق

- 179/179 اختبارات وحدات ناجحة (بعد إضافة اختبارات استيراد التلاميذ).

- 21/21 إصدار Migration محلي يطابق سجل Supabase.
- لم يُثبت بعد `npm run build` أو typecheck الكامل لأن `npm ci` انتهى بمهلة في بيئة العمل.
- لم تُنفّذ اختبارات RLS بأربعة حسابات حقيقية ومؤسستين، ولا اختبار SMTP/Edge Function أو أجهزة حقيقية.

## حدود معروفة

- Edge Function `invite-user` المنشورة أقدم من المصدر؛ تحتاج إعادة نشر بعد ضبط Secrets وURL النهائي لـCloudflare.
- Web Push بعد إغلاق التطبيق غير متاح. الإشعارات الحالية داخل التطبيق وRealtime وإشعارات المتصفح ما دام التطبيق مفتوحًا أو في الخلفية.
- يجب إكمال اختبار البناء والتكامل والأجهزة قبل إطلاقه لكل المؤسسات.

- استيراد Excel/CSV: تعرّف عناوين الأعمدة العربية والفرنسية والإنجليزية، مع معاينة جدولية قبل الحفظ.
- مرجع يومي جديد للغيابات والرخص والإعفاءات؛ يعرض للمدرب البيانات التشغيلية فقط دون تفاصيل طبية.
- صلاحية المدرب لقراءة قالب Word النشط فقط أُصلحت في Supabase.
